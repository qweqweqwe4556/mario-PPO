# Mario PPO v0.2.0

v0.2.0 将当前训练实验整理为可安装、可测试和可复现的阶段性版本。它增加了最长连续跳跃限制、只奖励新位置的奖励封装、确定性/随机双评估，以及从关卡中段恢复的混合课程训练。

## 发布内容

- Python wheel 和 source distribution
- Git 源码归档
- 完整关卡起点最佳模型 `full_level_best.zip`
- `x=2095` 前沿技能模型 `frontier_x2095_best.zip`
- 前沿动作配置、模型卡、资产清单和 SHA-256 校验值

## 验证结果

- 单元测试：5 项通过
- 游戏环境 smoke test：通过，观测为 `(84, 84, 1)`
- 完整模型：确定性 3 局均到达 `x_pos=2226`
- 前沿模型：随机 10 局全部越过 `x_pos=2300`，平均 2634.5，最大 2994
- 通关：两组均为 `flag_get=0`

## 已知问题

前沿技能尚未稳定整合回从关卡起点运行的策略。项目依赖旧版 Gym API，运行时会显示 Gym 维护状态和旧 step API 的警告；当前固定 NumPy `<2` 以维持兼容。

代码仓库未选择开源许可证。发布前若计划允许他人复制、修改或再分发代码，应由仓库所有者补充合适的许可证。
